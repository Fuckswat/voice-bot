# Бот для голосовых

Сделал бота, который помогает быстро понять, что сказали в голосовом, и придумать ответ.

Telegram-бот распознаёт голосовые сообщения, пересказывает их и предлагает вариант ответа. Распознавание делает faster-whisper, текст обрабатывает локальная модель через Ollama. Полную расшифровку можно открыть кнопкой под ответом.

## Установка

Нужны Python 3.11 или новее, установленная Ollama с моделью и токен бота от BotFather.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Открой `.env`, укажи `BOT_TOKEN` и модель в `OLLAMA_MODEL`, затем запусти:

```powershell
python bot.py
```

Модель Whisper может скачаться при первом запуске. Сообщения передаются через Telegram, а распознавание и Ollama при стандартной настройке работают на твоём компьютере. Расшифровки временно хранятся в SQLite. Не выкладывай `.env` и базу с сообщениями.
